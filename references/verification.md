# 交叉校验清单

两类东西最容易出错：**中文译名**和**机制方向**。两者都不是"读起来通顺"就能通过的。

## 一、术语三层校验

| 层级 | 做法 | 不合格表现 |
|---|---|---|
| 1. 课件原文 | 在 `slides.md` 搜到该词，摘原句，`slide` 列填实际页码 | 词在课件里根本没有（模型凭常识补的） |
| 2. 权威译名 | 术语在线(termonline.cn) → 教材附录 → MeSpEn | 自创译名，如把 `tight junction` 写成"紧密联结" |
| 3. 一致性 | 同一概念全篇只用一种译名；缩写首次出现给全称 | `ECM` 一处写"细胞外基质"，一处写"胞外基质" |

`check_glossary.py` 覆盖第 1 层（grounding）与字段完整性；第 2 层必须人工过一遍，
把结果写进 `cross_check` 列（`TermOnline:匹配` / `MeSpEn:匹配` / `Unverified`）。

## 二、已知的高频错译（细胞学）

| 英文 | 常见错译 | 正确 |
|---|---|---|
| tight junction | 紧密联结 / 致密连接 | 紧密连接 |
| gap junction | 缝隙连接（可接受）/ 间隙连接 | 缝隙连接（教材多作"缝隙连接"） |
| adherens junction | 黏附连接 / 粘着连接 | 黏着连接 |
| desmosome | 桥粒（对）/ 半桥粒混用 | 桥粒；半桥粒 = hemidesmosome |
| cytosol | 细胞质 | 细胞质基质（cytosol ≠ cytoplasm） |
| cytoplasm | 细胞液 | 细胞质（含细胞器） |
| cristae | 嵴（对）/ 与 cisternae 混 | 嵴；cisternae = 扁囊 |
| microvillus | 纤毛 | 微绒毛（cilium = 纤毛） |
| integral protein | 整合蛋白 / 内在蛋白 | 整合蛋白（跨膜蛋白是子类） |
| cell coat | 细胞外被（≈ glycocalyx） | 细胞外被；与"细胞壁"无关 |

## 三、机制类幻觉模式

写知识点时逐条自查：

1. **方向反了**：Na⁺/K⁺-ATPase 泵出 3 Na⁺、泵入 2 K⁺，不是反过来。
2. **主动/被动混淆**：协同运输(secondary active)靠的是**电化学梯度**，不是 ATP 直接水解。
3. **结构-功能错配**：紧密连接封 paracellular 途径；缝隙连接才是细胞间**通讯**通道。
4. **程度词**："全部""完全"——除非课件原文如此，改成"多数""部分"。
5. **因果倒置**：微丝参与胞质分裂的收缩环，是"执行"不是"触发"。
6. **把模型当事实**：流动镶嵌模型是模型，课件若说"目前广为接受"就不要写成"已证明"。

## 四、图片校验

- 图里标注的结构名，要和正文术语**用同一个中文名**。
- 一张图只讲一件事；如果图上同时有 5 个结构，正文必须点明"看哪三个"。
- 电镜图必须给标尺或放大倍数，否则读者无法判断尺度。
- 示意图（schematic）与显微图（micrograph）不能互换描述。

## 五、外部数据

star 数、样本量、发病率、分子量：只写课件给得起的；必须引外部时，
附可点开的 URL + 访问日期，且**两个独立来源一致**才写进正文。
